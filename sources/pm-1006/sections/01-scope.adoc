== Scope

=== General

This document specifies the pma notation:

* the design rules the notation is built under;
* the grammar surface and its token discipline;
* the constructors: `unit`, `ustd`, `uexp`, `ucov`, `diff`;
* the measured literals and their modifiers;
* quantity assertions and the static semantics they invoke;
* the rejected syntaxes, and what replaces each;
* materialization into the math model and the rendering relationships to AsciiMath;
* the artifact and runtime model;
* conformance.

This document does not specify: the model the notation materialises into (PM 1001), the uncertainty fields (PM 1002), the evaluation that will consume it (PM 1004), the units grammar behind `unit(...)` (UnitsML 6), or the quantity semantics behind the assertions (UnitsML 4 and 5) — each is referenced where it applies.
