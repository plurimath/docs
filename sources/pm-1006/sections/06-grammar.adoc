== The grammar

=== General

The grammar of pma is stated here in full, in PARG — the grammar language of the asciiunits artifact pattern (UnitsML 6) — as the normative source the pma artifact generates from. A developer implements the reader from this grammar, the materialization rules of clauses 7 and 8, and nothing else: every input is derivable to exactly one tree, or refused by exactly one error.

The unit expressions inside `unit(...)` are not re-stated here: the rule references the UnitsML 6 grammar (the `UnitsmlAscii` artifact), embedded by reference at compile time — one unit grammar, two notations.

=== The grammar

[source,parg]
----
# The pma grammar: arithmetic core, measurement constructors, measured
# literals, quantity assertions. Edition 1. Generated into the pma
# artifact; reserved words are checked against the registry's symbol
# space and the UnitsDB symbol space at generation time.

grammar Pma version "0.1.0" edition 1 {

  # lexical terminals
  ws = %x09 / %x0A / %x0B / %x0C / %x0D / %x20
  spaces = 1*ws
  digit = %x30-39
  digits = 1*digit
  lparen = "("
  rparen = ")"
  comma = ","
  plus = "+"
  minus = "-"
  star = "*"
  slash = "/"
  caret = "^"
  percent = "%"
  e_mark = "e"
  tilde = "~"
  colon_colon = "::"
  plus_slash_minus = "+/-"
  plusminus = "±"
  equals = "="
  not_equals = "!="
  lt = "<"
  le = "<="
  gt = ">"
  ge = ">="

  number = (["-"] digits ["." digits]) as number

  # names: identifiers for evaluation bindings. The name table is
  # generated as the identifier shape minus the reserved words — the
  # same generation-time subtraction the unit tables use.
  letter = %x41-5A / %x61-7A
  underscore = "_"
  name = (letter 1*(letter / digit / underscore)) as name

  # the reserved words: checked against registry ∪ unitsdb at generation
  reserved_unit = "unit"
  reserved_ustd = "ustd"
  reserved_uexp = "uexp"
  reserved_ucov = "ucov"
  reserved_diff = "diff"

  # distribution tags: the closed set
  tag_name = ("rect" / "tri" / "u") as distribution

  # unit expressions: the UnitsML 6 grammar, embedded by reference
  unit_expression = @UnitsmlAscii.expression

  kind_name = from_table "kinds" column "name" as kind

  # ---- expressions ----

  expression = relation

  relation = additive [ (equals / not_equals / lt / le / gt / ge) additive ]

  additive = multiplicative 1*((plus / minus) multiplicative)

  multiplicative = unary 1*((star / slash / keyword_mod) unary)
  keyword_mod = "mod"

  unary = [plus / minus] power

  power = primary [caret unary]

  primary = number / literal / constructor_call / name / (lparen expression rparen)

  # ---- measured literals ----

  literal = lparen number plus_slash_minus magnitude rparen [exponent] [tag] [trailing_unit] as literal
  literal_sugar = lparen number plusminus magnitude rparen [exponent] [tag] [trailing_unit] as literal
  magnitude = (number [percent]) as magnitude

  exponent = e_mark ["-"] digits as exponent
  tag = tilde tag_name as tag

  # ---- constructors ----

  constructor_call = ustd_call / uexp_call / ucov_call / diff_call / unit_call

  ustd_call = reserved_ustd lparen number comma [spaces] number rparen [trailing_unit]
  uexp_call = reserved_uexp lparen number comma [spaces] number comma [spaces] number [comma [spaces] number] rparen [trailing_unit]
  ucov_call = reserved_ucov lparen number comma [spaces] number comma [spaces] number [comma [spaces] number] comma [spaces] kind_name rparen [trailing_unit]
  diff_call = reserved_diff lparen expression rparen
  unit_call = reserved_unit lparen unit_expression [colon_colon kind_name] rparen

  trailing_unit = unit_call

  # ---- entry ----

  entry pma: expression

  test pma {
    accept "(10.3 +/- 0.2) unit(m)"
    accept "(10.3 +/- 2%) unit(m)"
    accept "(3.85 +/- 0.23)e4 unit(m)"
    accept "(0.5 +/- 0.01) ~rect unit(m)"
    accept "(10.3 ± 0.2) unit(m)"
    accept "ustd(10.3, 0.2) unit(m)"
    accept "uexp(10.0, 0.3, 2, 0.95) unit(cm)"
    accept "ucov(10.0, 9.7, 10.3, 0.95, shortest) unit(cm)"
    accept "ucov(10.0, 9.7, 10.3, probabilistically-symmetric)"
    accept "unit(kg m/s^2)"
    accept "unit(Bq)::frequency"
    accept "diff(5 unit(degC))"
    accept "x^2 + 1"
    accept "2 * (3 + 4)"
    reject "10.3(2)"
    reject "3+-1"
    reject "10.3 +/- 0.2"
    reject "(0.5 +/- 0.01) ~magic"
    reject "2x"
    reject "\"unitsml(g)\""
  }
}
----

=== Reading the grammar

* The repetition, option and alternative operators are PARG's (`1*`, `[...]`, ordered `/`), as in the asciiunits artifact; the ordered choice makes the alternative order decisive, exactly as it is there.
* The `as` captures name the tree positions the materializer consumes: `number`, `name`, `literal`, `magnitude`, `exponent`, `distribution`, `kind`.
* The `name` rule's table is generated as the identifier shape minus the reserved words — the generation-time subtraction, the same discipline the unit tables use, so a reserved word can never read as a name.
* `@UnitsmlAscii.expression` embeds the UnitsML 6 grammar by reference at compile time; the unit expressions carry that grammar's captures into the tree under the unit node.
* The `test` block is normative: the artifact's conformance runs the accepts and rejects on every build, and this document's vectors extend them.

=== What the grammar deliberately lacks

* *No quoted strings.* There is no double-quote token; a quote anywhere is a lexical error (clause 10).
* *No implicit multiplication.* Adjacency is not an operator: `2x` does not derive, and the test block rejects it. Multiplication is written `*`.
* *No comments.* A pma input is one expression; there is nothing to comment.
* *No statement terminators or sequences.* Edition 1's input is one expression; sequences are an edition's addition, with their separator.
* *No subscript.* The `_` token does not exist; `^` is the power operator only.

What each derivation yields, for the materializer:

|===
|Production |Captures consumed |Node materialised

|`literal` |number, magnitude, exponent, distribution, trailing unit |the desugared uncertainty record (clause 8)
|`ustd_call`, `uexp_call`, `ucov_call` |the number captures, the kind |the uncertainty record per PM 1002
|`unit_call` |the unit expression, the kind |the `Unitsml` node, assertion recorded
|`diff_call` |the operand expression |the difference-typed quantity (clause 12)
|`number`, `name` |the text |`Number`, the binding name
|the operators |the folded operands |the model's operators (PM 1004's chain)
|===

=== Completeness, stated

The grammar derives every input this document's clauses describe and nothing else. A form the clauses describe but the grammar does not derive is a defect in one of the two; a form the grammar derives but no clause describes is likewise. The test block, the vectors of Annex E, and the clause cross-checks are the mechanics of that statement — the statement itself is the standard this document is held to.
