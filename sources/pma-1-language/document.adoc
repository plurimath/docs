== Foreword

pma (plurimath ascii) is where features live. It is a new language, owned end to end: reserved words are grammar terminals, `+/-` is one token, errors are strict, and nothing is sugar over a legacy parser. Its grammars are generated from the shared registry; its materialization target is the math model; its conformance is the frozen corpus. It has no compatibility obligation until first release, and an edition-based one afterwards.

== Scope

This document specifies: the design rules; the constructors; the measured literals; quantity assertions and static semantics; the rejected syntaxes; and materialization.

== Normative references

* Plurimath 1 (model, registry); Plurimath 2 (uncertainty model); UnitsML 6 (`unit(...)` content grammar), UnitsML 4, UnitsML 5 (static semantics), UnitsML 2 (numeric contract)

== Design rules

. **Owned grammar** — reserved words are terminals; the build fails on any collision between reserved words and registry ∪ unitsdb symbols/names (verified empty for `unit`, `ustd`, `uexp`, `ucov`, `diff`, `quantity`).
. **Explicit input** — values are typed explicitly; reporting conventions are output-only (concise: Plurimath 2).
. **Strict errors** — malformed forms are parse errors; there is no fallback-to-letters and no load-bearing whitespace.
. **No strings-as-syntax** — the legacy quoted-channel trick does not exist here; `unit(...)` is unquoted.
. **No conversion syntax** — conversion is an evaluation operation (Plurimath 4).

== Constructors

Atomic `keyword(args)` forms; malformed = parse error.

[listing]
unit(kg m/s^2)                            unit expression — UnitsML 6 grammar
ustd(10.3, 0.2) unit(m)                   measured value, standard u
uexp(10.0, 0.3, 2, 0.95) unit(cm)         expanded U with k, p
ucov(10.0, 9.7, 10.3, 0.95, shortest)     coverage interval
diff(5 unit(degC))                        difference-typed quantity (name open: diff/delta/∆)

A trailing `unit(...)` scopes value AND uncertainty magnitude (the magnitude is a difference in that unit). Constructors materialize as single math-model nodes.

== Measured literals

[listing]
(10.3 +/- 0.2) unit(m)          canonical
(10.3 +/- 2%) unit(m)           relative — stored as absolute magnitude, exact rational u = value·p/100
(3.85 +/- 0.23)e4 unit(m)       shared exponent — value and magnitude shift together
(0.5 +/- 0.01) ~rect unit(m)    distribution tag — closed JCGM family set (rect, triang, arcsine, normal, cauchy, lognormal, gamma, t, ctrap)
(10.3 ± 0.2) unit(m)            ± sugar — fenced only; `+/-` remains canonical ASCII

`+/-` is ONE terminal: `3 +/- 1` cannot re-lex as `3 + (/1)`; `3 + (-1)` remains arithmetic. `~` tags are Type-B distribution INPUTS; Type A/B provenance is evaluation metadata, never syntax.

== Quantity assertions and static semantics

`unit(J::energy)` asserts the L1 quantity: the right side resolves per UnitsML 4 (short → unitsml id → nist id, exact tokens) and is validated against the unit record's membership (or the dimension check for unregistered composites). `::` is the lowest-precedence operator inside `unit(...)`, binding the whole preceding expression; subterm annotation requires parentheses. Static checks — membership, scale legality, difference typing (UnitsML 4) — run before evaluation; the evaluator (Plurimath 4) consumes already-checked trees.

== Rejected syntaxes

- Concise `10.3(2)` as input (`n(d)` reads as multiplication/application; concise is output-only — Plurimath 2).
- `+-` (Python `uncertainties` precedent); `pm`/`\pm` (picometre).
- Conversion syntax (conversion is an API operation).
- Implicit-multiplication readings of `n(d)`-shaped input.

== Materialization and the artifact contract

The pma grammar is generated from the registry edition; the checksummed artifact is normative; materialization maps into the math model like every front end. Rendering into the legacy dialect goes through the asciimath 2 quoted channel.

== Conformance

Annex A defines the pma corpus: every form of Clauses 6–8 parses to the specified model; every malformed form is a parse error with the specified class; render replay per UnitsML 8.
