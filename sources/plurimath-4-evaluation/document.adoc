Requirements: plurimath#514 (R-C1–C6) and plurimath#523 (refinements). The reference implementation is the next major build item; this part is its normative specification. Annex A carries the H.1.7 second-order derivation.

== Abstract

Evaluation is a pure function (AST, bindings) → result over the Plurimath math model. The evaluation surface: the bindings model (measured quantities, covariance/correlation channel, L2 dedicated-quantity metadata), the `convert` API (the UnitsML 5 law; factor-only for differences; gating per UnitsML 4), and the result taxonomy `value | indeterminate | error | lpu-not-validated`. GUM propagation: Type A (series statistics, ν = n−1) and Type B distributions (rectangular a/√3, triangular a/√6, U-shaped a/√2, normal U/k, exact-where-possible per UnitsML 2); the law of propagation with symbolic sensitivity coefficients and the GUM-6:2020 Annex F finite-difference fallback; correlated inputs; Welch–Satterthwaite ν_eff and t-coverage (versioned quantile algorithm per UnitsML 2); the LPU-ADEQUACY VERDICT as a first-class outcome (2N-point check or MCM validation — GUM-5 Ex 2.6.3: "blind adherence to either approach would be dangerous"); second-order terms per JCGM 100:2008/Amd.1:2026 4.1.4 NOTE 1 (estimate correction ½Σ f_ii·u²(x_i), H.10 correlated form, normal-inputs-only gating, Hessians). Monte Carlo per JCGM 101 (distribution families, adaptive δ = ½·10^ℓ, coverage intervals in both kinds, pinned Wichmann–Hill with seed stamps; reproducibility classes). Conformity decisions per JCGM 106 (conformance probability, Table 1 z-values, simple and guarded acceptance/rejection w = r·U, ISO 14253-1 ceiling, C_m = T/(4u_m), specific risks; global risks deferred). Expanded uncertainty propagates only through validated-linear models; coverage intervals without an underlying u are refused.
