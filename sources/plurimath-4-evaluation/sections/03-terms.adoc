== Terms, definitions and abbreviated terms

sensitivity coefficient::
c_i = ∂f/∂x_i at the input estimates; the multiplier of u(x_i) in propagation.

adequacy verdict::
the first-class outcome stating whether the linear propagation is validated for the given inputs.

guard band::
w = r·U, the buffer subtracted from (or added to) a tolerance limit before acceptance decisions.

conformance probability::
p_c = ∫_C g(η|y)dη, the probability that the measurand lies in the conformity set C.

reproducibility class::
byte-exact or distributional (UnitsML 8, Clause 9).
