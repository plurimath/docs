== Status of this draft

The `"unitsml(...)"` channel is implemented and shipped; the uncertainty channel is specified (rendering side implemented in the merged uncertainty work). Formalizes the channel mechanism and the ledger discipline.

== Abstract

The only extension mechanism of the asciimath dialect: quoted compatibility syntax riding asciimath's own `"…"` string literal — every other asciimath processor sees a harmless text string; plurimath dispatches on the content namespace. Channels: `"unitsml(...)"` (content parsed by the UnitsML 6 artifact grammar) and `"ustd(10.3, 0.2)"` (the uncertainty channel; rendering uncertainty into asciimath is via this quoted form only). Malformed recognized-name channels raise `InvalidUncertainty`. Adding a namespace: `"<name>(...)"` + normative content grammar + ledger entry + edition. Bareword uncertainty call forms are absent — never released, re-homed as pma constructors.
