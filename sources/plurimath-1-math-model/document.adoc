== Foreword

The Plurimath series specifies the central math model of the stack and the languages and formats around it. Its center is the MODEL: a dialect-free formula tree into which every input language materializes and from which every output format renders. The companion UnitsML series (unitsml/docs) owns units, quantities, conversions, the register and the XML; this series references it at exactly three seams: the unit-expression content language (UnitsML 6), the units semantics (UnitsML 4, 5) and the conformance corpora (UnitsML 8).

== Scope

This document specifies: the formula tree and its primitive classes; the shared registry (vocabulary v2) — registered strings mapped to layout class and primitive binding, tagged by dialect, from which the input-language grammars are generated, with unit terminals composed from the UnitsML 6 artifact and reserved-word collision CI; model serialization via LML declarations (lutaml-model#1033 codegen contract); and the materialization contract — parse trees from any input language map into this one model.

== Normative references

* UnitsML 1 (procedures, terms), UnitsML 6 (unit expression content language)
* MathML 4 (W3C), OOXML/OMML, UnicodeMath linear format
