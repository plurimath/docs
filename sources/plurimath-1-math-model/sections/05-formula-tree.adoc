== The formula tree

The model is a tree of: `Formula` (the root list), `Symbol`, `Number`, operator and function nodes (`Function::Frac`, `Function::Sqrt`, `Function::Power`, …), grouping (`Fenced`), the `Unitsml` node (a unit expression embedded in math — UnitsML 6), and the `Uncertainty` node (Plurimath 2). Nodes carry:

- **exact decimal text** wherever a number is held — preserved verbatim, never reformatted (`2.10 ≠ 2.1`);
- **no semantic defaults**: a node records what the author wrote; evaluation semantics live behind the evaluator boundary (Plurimath 4);
- **dialect freedom**: no node records which input language produced it.

[example]
*Expected outcome.* Parsing `2.10` in any input language yields a `Number` whose text is exactly `"2.10"`; rendering to any format reproduces those bytes. Normalizing to `2.1` anywhere is a defect.
