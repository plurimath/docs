== Foreword

=== General

This document is the third document of the Plurimath specifications series. It specifies the format interfaces: the readers that turn text and markup in each supported notation into the formula tree, the writers that turn the tree back out, the error behaviour at each boundary, and the round-trip properties that connect them.

The interfaces described here are implemented in the `plurimath` gem of the 0.11 series. Where this document and the implementation disagree, the disagreement is a defect in one of the two.
