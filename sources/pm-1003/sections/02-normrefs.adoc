== Normative references

The following documents are referred to in the text in such a way that their content applies to the construction of these interfaces.

* [[[pm1001,nofetch(PM 1001 (math model))]]] of this series.
* [[[pm1002,nofetch(PM 1002 (uncertainty model))]]] of this series.
* [[[mathml4,nofetch(MathML 4)]]], W3C Recommendation — the `intent` attribute and `semantics` element as read by the MathML interface.
* [[[ecma376,nofetch(ECMA-376)]]], Office Open XML File Formats, Part 1 — the DrawingML mathematics the OMML interface reads and writes.
* [[[utr28,nofetch(Unicode Technical Report #28)]]], Unicode Support for Mathematics — the linear format the UnicodeMath interface reads and writes.
* [[[cc36817,nofetch(CalConnect 36817 (asciiunits content language))]]] of the UnitsML series — the content of the quoted channel the AsciiMath interface reads and of the unit embedding.
