== The writer contract

=== Entry points

A tree writes to each surface through one entry point: `to_asciimath`, `to_mathml`, `to_omml`, `to_latex`, `to_unicodemath`, `to_html`. The surfaces, their outer elements and their stability rules are PM 1001's; this document adds the interface obligations.

.Writers and obligations
[cols="2,3,3", options="headers"]
|===
|Entry point |Obligation this document adds |Reads back

|`to_asciimath` |emits the call forms and reporting forms that clause 8 reads |yes
|`to_mathml` |emits intent markers that clause 9 reads |yes
|`to_omml` |emits marker runs that clause 10 reads |yes
|`to_unicodemath` |emits the intent wrapper that clause 11 reads |yes
|`to_latex` |emits shapes and statements; display surface |no
|`to_html` |emits shapes and statements; display surface |no
|===

=== Determinism

Writers are deterministic and byte-stable per PM 1001. This document adds: a writer emits only through its own boundary — no writer depends on a reader having produced the tree, and no writer consults the tree's `input_string`.

=== The display-style option

The root's display flag (PM 1001) may be forced per call: a writer asked for display style renders the display form regardless of the root's flag, and one asked for inline renders inline. Absent an override, the root's flag decides.

=== Failure

A writer given a well-formed tree does not fail. A writer given a tree that violates PM 1001 — an operand missing, an unknown node class — is outside the contract; implementations report it as a programming error, not as a parse or rendering error.

Every cell is discharged by the corpora: each family's row in each surface's column has corpus vectors, and a writer claim covers its column end to end.

=== Writing what was not read

A tree may be built by construction — an application assembling nodes — rather than by reading. Writers treat constructed trees identically: the boundary knows no difference between a read tree and a built one. This is what makes evaluation pipelines possible: document 1004's output trees write like any others.

=== Idempotence of shape

Writing a tree twice yields identical bytes. Writing a read-back tree yields the same bytes as writing the original: the round-trip property plus writer determinism give write-read-write idempotence per lossless format. The corpora assert it.
