== The registry (vocabulary v2)

The registry is the series' terminal dictionary, evolved from the amath vocabulary (`format: amath-vocabulary/v1`, oracle-recorded). v2 entries are:

[listing]
{ string, layout_class (symbol | bold_fonts | binary_class | ternary_class |
  sub_sup_class | …), primitive (the model node the string materializes to),
  dialects: [legacy, pma] }

Rules:

- Both input-language grammars are GENERATED from the registry; the legacy snapshot is pinned by edition and never sees `pma`-only entries.
- Unit terminals are composed from the UnitsML 6 artifact — referenced, never copied.
- The registry records provenance (generating revision) as its oracle did.

[example]
*Expected outcome.* Registering `triangle` with binding `Symbol`, dialects `[legacy, pma]` makes it parseable in both dialects after one regeneration; registering a pma-only constructor never appears in the regenerated legacy grammar.
