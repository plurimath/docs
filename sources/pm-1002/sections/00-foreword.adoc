== Foreword

=== General

This document is the second document of the Plurimath specifications series. It specifies the uncertainty model: the node that carries a measured value together with its uncertainty through the Plurimath system, the categories of uncertainty it represents, the discipline that governs the numbers it carries, and the representation of each category in every output format.

The model described here is implemented in the `plurimath` gem of the 0.11 series (the `Plurimath::Math::Function::Uncertainty` class). Where this document and the implementation disagree, the disagreement is a defect in one of the two.
