== Conformance

=== General

Conformance to this document is the implementation of the evaluator per clauses 5 to 11. One class covers it, with the corpus as its evidence; a partial implementation claims nothing.

=== Conformance classes

.Conformance classes
[cols="1,3,3", options="headers"]
|===
|Class |Licenses the implementation to claim |Replay requirements

|evaluation
|evaluates trees against bindings per this document |the evaluation corpus: results, errors, and message shapes, replayed identically
|===

The claim carries the model claim of PM 1001: an evaluator over trees is an implementation of trees first.

=== The evaluation corpus

The corpus freezes, per entry: the tree (in a canonical reading), the bindings, and the outcome — the exact result or the typed error with its message shape. Entries come from this document's examples first and from defect fixes and community reports as they arrive; a generation is immutable once published.

=== Drift

An implementation whose result or error differs from the corpus for the same tree and bindings does not conform. Floating-point-order differences that change results are drift: the corpus, not the platform, defines the expected values, and an implementation adjusts or the document moves an edition.
