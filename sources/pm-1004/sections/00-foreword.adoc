== Foreword

=== General

This document is the fourth document of the Plurimath specifications series. It specifies evaluation: the computation of a numeric value for a formula tree against variable bindings, under a strict error contract.

The evaluator described here is implemented in the `plurimath` gem of the 0.11 series (`Plurimath::Math::Evaluation`). It evaluates arithmetic over the tree exactly as written: it never rewrites the tree, never rounds behind the caller's back, and never returns a value that is not a real, finite number — the alternative is one of the typed errors. Uncertainty propagation is not part of this edition: the model of PM 1002 carries uncertainty nodes, this document's evaluator does not compute with them, and the propagation rules will arrive in this document when they arrive in the implementation.
