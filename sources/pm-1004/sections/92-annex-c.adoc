== Annex C: test-suite examples

Vectors illustrative of the evaluation corpus. Each states the tree, the bindings, and the outcome.

=== Results

[example]
`x^2 + 1` with `x → 3`.
*Expected outcome.* `10`.

[example]
`2^3^2`.
*Expected outcome.* `512` — right-associative powers.

[example]
`(a + b) * (a − b)` with `a → 5`, `b → 2`.
*Expected outcome.* `21` — groups first, then the product.

[example]
`sum_(i=1)^4 i^2`.
*Expected outcome.* `30`.

[example]
`prod_(i=1)^4 i`.
*Expected outcome.* `24`.

[example]
`sum_(i=5)^4 i`.
*Expected outcome.* `0` — the empty range, no error.

[example]
`i + sum_(i=1)^3 i` with `i → 10`.
*Expected outcome.* `16` — shadowing scoped to the body; the outer binding survives.

=== Refusals

[example]
`1/0` and `x/(y − y)` with any `x`, `y` bound.
*Expected outcome.* `DivisionByZeroError` — the second through an evaluated zero.

[example]
`sqrt(−1)` written as a power `(−2)^(1/2)`.
*Expected outcome.* `MathDomainError`.

[example]
`log(0)`.
*Expected outcome.* `MathDomainError`.

[example]
`x + 1` with no bindings.
*Expected outcome.* `MissingVariableError` carrying `x`.

[example]
The tree of a text node: `text("hello")`.
*Expected outcome.* `UnsupportedExpressionError` naming the node class.

[example]
A tree containing an uncertainty node (PM 1002).
*Expected outcome.* `UnsupportedExpressionError` — clause 12's rule, tested.

[example]
The binding `x → "three"`.
*Expected outcome.* `InvalidBindingError` with the key and value.

[example]
The binding key `2`.
*Expected outcome.* `InvalidBindingKeyError` with the key.

[example]
An exponentiation whose magnitude overflows the platform's numbers.
*Expected outcome.* `NonFiniteResultError` at the fold, not at the end — intermediate checks refuse early.

=== Determinism

[example]
The same tree and bindings evaluated twice, in one process and across processes.
*Expected outcome.* the identical result or the identical error, every time; the corpus replays the whole set.

=== Precedence vectors

[example]
`−3 + 4 * 2^2 / (1 + 1)`.
*Expected outcome.* `5`, per the walk of Annex A.

[example]
`8 / 4 / 2`.
*Expected outcome.* `1` — left-associative division.

[example]
`2 − 3 − 4`.
*Expected outcome.* `−5` — left-associative subtraction, not `3`.

=== Binding vectors

[example]
`:x` and `"x"` given together with different values.
*Expected outcome.* one binding, the last given; the corpus pins which spelling survives.

[example]
A rational binding `1/3` in `x * 3`.
*Expected outcome.* `1` — exact under the platform's rational arithmetic, and the corpus states the type-observable result.

=== Iteration vectors

[example]
`sum_(i=1)^n i` with `n → 0`.
*Expected outcome.* `0` — the empty range for a bound that evaluated to zero.

[example]
A range past the step limit.
*Expected outcome.* `UnsupportedExpressionError` naming the iteration; the limit's edge is a corpus vector on both sides.
