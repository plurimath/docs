== Foreword

=== General

This document is the thirteenth document of the Plurimath specifications series. It specifies the embedded-consumer contract: the serialized request surface over which a host — the Primmel kernel, a document pipeline, a TS application — drives the evaluation, the artifact-sharing discipline that keeps one grammar and one model definition across the runtimes, and the parity claims that make the cross-runtime behaviour a conformance statement instead of a hope.
