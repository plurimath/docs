== Foreword

This document is the first document of the Plurimath specifications series. The series documents the Plurimath formula system as implemented by the `plurimath` interpreter: the math model shared by every input and output representation (this document), the uncertainty model, the format interfaces, and the evaluation semantics.

The math model described here is the one implemented in the `plurimath` gem, version 0.11.12 and later of the 0.11 series. Where this document and the implementation disagree, the disagreement is a defect in one of the two, and is resolved in favour of whichever is corrected first; the series does not describe an unimplemented design.

=== Maintainers

This document is maintained by the Plurimath project at https://github.com/plurimath/plurimath. Corrections and implementations are tracked as issues in that repository.

=== Stability of this document

This document is a draft standard. The model it describes is implemented and released; the document pins behaviour to model versions so that readers can tell which statements describe released software and which anticipate the next edition. Corrections that change observable behaviour arrive with a model-version change and are recorded here; corrections that only clarify arrive at any time.
