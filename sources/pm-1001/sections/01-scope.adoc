== Scope

=== General

This document specifies the math model of the Plurimath system:

* the formula tree and its ownership rules;
* the node classes — formula containers, symbols, numbers, functions, tables, font styles, unit embeddings and uncertainty nodes — with their attributes and relationships;
* the registry of symbols and functions, its entry shape, its generation and its versioning;
* the rendering surfaces: the contract each output format satisfies and the stability rules that govern them;
* the rules by which the model is extended;
* conformance of an implementation of this model.

This document does not specify:

* the syntax of any input representation, or the behaviour of any reader (format interfaces, document 1003);
* the representation of uncertainty inside specific notations, nor uncertainty arithmetic (uncertainty model, document 1002);
* numeric evaluation, propagation or coverage (evaluation, document 1004);
* the UnitsML unit-expression language, which is specified in the UnitsML series (asciiunits content language, UnitsML 1006), and is consumed by the model through the `Unitsml` node defined here.
