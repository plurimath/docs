== Conformance

=== General

== Conformance

Conformance to this document is claimed per class, and every claim is discharged by replaying frozen vectors. Nothing in this clause is satisfied by assertion alone.

=== What conformance covers

An implementation of this document is an implementation of the math model: the tree, the node classes of <<annex-a>>, the registry behaviour, and the writers of the six surfaces. Readers and the uncertainty and evaluation semantics are covered by documents 1003, 1002 and 1004; conformance to those documents is claimed separately.

A conformance claim names the classes it makes. A claim of `render-<format>` carries `model` with it: no surface can be claimed without the tree it renders.

=== The render corpus

The render corpus is a frozen set of trees and, per surface, their expected bytes. A corpus entry states its provenance (the tree's construction, the model version that froze the bytes) and is replayed without modification. Corpus bytes change only at an edition: a new corpus entry joins frozen; a frozen entry never changes.

=== Drift

An implementation whose output for any frozen entry differs from the corpus bytes does not conform at the model version the corpus was frozen against, whatever its own version string says. Divergence is resolved by a model-version change and a new corpus entry, or by fixing the implementation.
