== Annex A: node class reference

=== General

This annex enumerates=== General

This annex enumerates every function class of the model at this edition: 103 function classes, 14 font styles and 10 table classes. The list is normative. A class's operands column uses `1`, `2`, `3`, or "rows" for the table containers.

The operand shape of each class is the family it belongs to in <<formula-tree>>: the `Elementary` and `Trigonometric` classes are unary with an optional limit where their input notation carries one; `Log` and `Lg` are unary with an optional base operand; the `ScriptPlacement` classes are binary (`Power`, `Over`, `Underset`, and the rest) or ternary (`PowerBase`, `Underover`); the `Calculus` classes are nary; the `Tables` containers hold rows. The tables below give the semantics and surface notes per class.

=== Font styles

The 14 font style classes apply a mathematical font variant to their operand. Each carries one operand; the surfaces carry the variant per the mapping.

.Font style classes
[cols="1,3,3,3", options="headers"]
|===
|Class |MathML |LaTeX |UnicodeMath

|bold |mathvariant="bold" |mathbf{} |bold alphanumeric range
|italic |mathvariant="italic" |mathit{} |italic alphanumeric range
|bold-italic |mathvariant="bold-italic" |oldsymbol{} |bold-italic range
|sans-serif |mathvariant="sans-serif" |mathsf{} |sans-serif range
|sans-serif-italic |mathvariant="sans-serif-italic" |mathsfit{} |sans-serif-italic range
|sans-serif-bold-italic |mathvariant="sans-serif-bold-italic" |mathsfbfit{} |sans-serif-bold-italic range
|bold-sans-serif |mathvariant="bold-sans-serif" |mathsfbf{} |bold sans-serif range
|monospace |mathvariant="monospace" |mathtt{} |typewriter range
|fraktur |mathvariant="fraktur" |mathfrak{} |fraktur range

Where an alphanumeric range does not exist for a character, the UnicodeMath surface renders the plain character with the variant dropped, per the fallback rule.
