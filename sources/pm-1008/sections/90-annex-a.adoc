== Annex A: examples of the typed model

These results were produced by parsing each input with `Umath.parse` at the pinned `umath` commit and printing the non-empty fields of the model. A symbol is shown as `MathSymbol(spelling)`; the spelling is the encoded text the grammar matched. Fields inside each class are printed in the order the class declares them, not in input order.
