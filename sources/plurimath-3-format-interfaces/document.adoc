== Status of this draft

The renderers are implemented and corpus-frozen (`unitsml/unitsml-testsuite` render corpus); this part formalizes the general (non-uncertainty) interface contract. Uncertainty encodings are in Plurimath 2.

== Abstract

Per supported format, the model↔format contract: primitive mappings (`mn`/`mi`/`mo`, `mfrac`, `msqrt`, `mrow`); decimal-text verbatim emission (never reformatted, never float-normalized); the `unitsml(...)`/`unit(...)` rendering as visible symbol + `xref` into the UnitsML 7 `xml:id` space; and per-format readers. MathML 4: reader decodes `intent` markers (Plurimath 2); `$unit` re-reads as formula — recorded limit. OMML: `m:oMath` mapping; Word round-trip caveats. UnicodeMath: linear output; `ⓐ(...)` units. LaTeX: output-only. HTML: presentation fallback; `data-*` annotation proposed. Ambiguity between unit symbols and math identifiers is resolved exactly by the embedding constructors, never by heuristics.
