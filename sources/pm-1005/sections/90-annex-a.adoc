=== Sub/sup readings

`lim` reads to the limit class with optional scripts; `log` reads to the logarithm with optional base scripts. Both take the operand adjacency gives and the scripts the input writes.

=== The unary readings, worked

.Worked unary cases
[cols="2,4", options="headers"]
|===
|Input |Reading

|`sqrt x` |`Sqrt` over `x` — the adjacency operand
|`sqrt(x^2 + 1)` |`Sqrt` over the sum — the grouped operand
|`bar x`, `hat x`, `vec x` |the accent classes — one operand each
|`abs x`, `norm x` |the fence classes — the delimiters ride the node
|`floor x`, `ceil x` |the floor and ceiling fences
|`obrace x`, `ubrace x`, `underbrace x`, `overbrace x` |the brace forms
|`cancel x`, `underline x`, `ul x` |the strike and underbar forms
|`sin x`, `cosh x`, `arctan x` |the trigonometric, hyperbolic and inverse classes
|`ln x`, `log x`, `exp x` |the logarithmic and exponential classes
|`gcd x`, `lcm x`, `glb x`, `lub x` |the binary-named-but-unary classes — one operand in the notation
|`det x`, `dim x`, `max x`, `min x` |the operator-name classes
|`ddot x`, `tilde x`, `dot x` |the remaining accents
|`text x` |upright text — adjacency form of the text function
|===

The last-but-one row is the table's trap: `gcd`, `lcm`, `glb`, `lub`, `max` and `min` are unary classes in this notation, whatever their arity in mathematics — an author who means `gcd(a, b)` writes it as a product-adjacency the reader splits, and the corpus pins the split. The comma form is not a two-argument call; grouping composes.
