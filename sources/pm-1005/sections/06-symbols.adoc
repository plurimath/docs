== Symbols

=== The symbol surface

The symbol tokens are the registry's AsciiMath tokens (PM 1001's symbol space, 1 438 entries at edition 1). A symbol token reads to its registry entry's `Symbol` node and nothing else: no arguments, no variants. The families:

The complete listing is generated from the registry; Annex D shows the families with their full member counts. The reader resolves a token by longest match — `==> ` reads as one arrow, not `==` then `>` — and an unresolvable token is a reading error naming the token and its position.

=== Fractions of the surface: what the public definition adds

*Compatibility note.* Plurimath's token set is a superset of the asciimath.org set: the uncertainty tokens of clause 12, the UnitsML channel of clause 11, and additional symbols the registry carries. The public set reads unchanged; nothing in the baseline was removed or re-spelled.

=== Case sensitivity

Tokens are case-sensitive: `alpha` and `Alpha` are different entries, `EE` (the special bold E) differs from `ee`. There are no aliases that differ only by case.

=== Numbers are not symbols

Digits and decimal points read as `Number` nodes (clause 7), never as symbol tokens; the reader's token classes are disjoint by first character.

=== Symbol vs construct: the classification rule

A token first matches the construct and font names (clause 8), then the special alphabets, then the symbols. The classification is total and ordered; `sum` can never be a symbol, `d` can never be a construct. The constants carry the order, and the generated tables of the annexes are that order's statement.

=== Unicode and entities

Input is Unicode text: symbol tokens are the spellings the registry declares, and a character outside every token's set is an unresolvable run — named, positioned, refused. The reader does not decode HTML entities in AsciiMath input (the writer emits character references in some surfaces; that is output encoding, not input syntax). An author pasting rendered mathematics strips the entities first, or the reader will name every ampersand.

=== The registry is the whole truth

Every token this clause lists is a registry entry's AsciiMath token, and every registry entry's AsciiMath token is accepted. Neither side of that sentence bends: no unlisted token reads, and no listed token fails. When the registry grows (PM 1001's entry lifecycle), the token surface grows with it at the next edition, and the generated tables of this document regenerate with it.
