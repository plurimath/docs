== The grammar artifact

=== The artifact pattern

The grammar of this notation is carried by a checksummed artifact, in the pattern of the asciimath and pma artifacts: the grammar source is committed together with the files generated from it and their checksums, and consumers verify the checksums before use. The artifact bytes are authoritative. This document states the notation; the artifact makes it runnable; the two are not copied into each other. Where this document quotes the grammar, the quotation is a statement of what the pinned artifact accepts, and it is valid only for the checksums below.

=== Rule for the excerpts

An excerpt of the grammar in this document is normative only as a statement about the pinned artifact. A change of the grammar changes the checksums; an implementation then makes a different claim (clause "Conformance"), and this document is revised to the new pin. The grammar is never edited by hand in this document.
